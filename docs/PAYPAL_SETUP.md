# PayPal setup

In PayPal Developer Dashboard → Apps & Credentials, create a Sandbox REST app and copy its client ID and secret. Add `https://socialbooster-sigma.vercel.app/api/webhooks/paypal`, subscribe to capture completed, denied, refunded and reversed events, and copy its webhook ID. Set `PAYPAL_ENVIRONMENT=sandbox` and keep `PAYMENTS_ENABLED=false` until testing. Social Booster creates and captures PayPal Orders server-side, verifies webhook transmission data with PayPal, matches amount/currency/reference to a stored payment intent, and credits the wallet idempotently. Replace all three credentials with Live app values only after sandbox verification.
