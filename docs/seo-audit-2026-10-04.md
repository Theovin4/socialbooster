# Technical SEO and analytics baseline

Date: 4 October 2026

## Before this pass

- One dynamic sitemap mixed public pages, guides and up to 1,000 service URLs.
- Search/filter variants were noindex, but service inclusion did not have a dedicated sitemap boundary.
- Public platform hubs, payment guidance and reseller guidance were incomplete.
- GA4 used useful custom funnel events, but did not also emit the recommended sign-up, login, item-list, checkout and purchase events.
- The admin had no dedicated index-governance view.

## Implemented

- Added a sitemap index with pages, platforms, Africa, guides and approved-service child sitemaps.
- Added explicit Googlebot and OAI-SearchBot public crawling rules while keeping authenticated and API routes blocked.
- Added canonical platform, payment, cryptocurrency and reseller hubs with internal links and structured data where appropriate.
- Added manual publish, feature, paid-ads and SEO eligibility governance to the service catalogue.
- Added consent-respecting GA4 recommended events and persistent browser deduplication for order purchase events.
- Added an admin search-health view and a query-to-page map.

## External verification required

- Google Search Console remains the source of truth for indexed URL counts, exclusions, Core Web Vitals, Discover and query performance.
- After deployment, submit only `https://www.socialbooster.net.ng/sitemap.xml`; the index references all child sitemaps.
- Search position and Discover inclusion cannot be guaranteed or truthfully manufactured in application code.
